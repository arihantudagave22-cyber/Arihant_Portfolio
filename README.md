# Arihant's Portfolio

A responsive React, TypeScript, Vite, and Tailwind portfolio. The hero scene uses Three.js to render original character designs; the city hero reacts to scroll speed, while a custom hammer animates into the welcome scene.

## Development

```powershell
npm install
npm run dev
```

## Checks and production build

```powershell
npm test
npm run typecheck
npm run build
npm run preview
```

Static images and the résumé are served from `public/`.
